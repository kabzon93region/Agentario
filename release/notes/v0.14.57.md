## Agentario v0.14.57

### Исправления

- **REST API полностью переработан**: все эндпоинты теперь читают данные из контроллера (in-memory) вместо поиска файлов в `tasks/`
  - SDK-сессии хранят данные в SQLite базе данных, а не в файловой системе
  - Старый подход с `findNewestTaskDir` не работал для SDK-сессий
  - Теперь `/api/status`, `/api/messages`, `/api/export_chat`, `/api/wait_idle`, `/api/collect` корректно получают данные из активной сессии
  - `/api/context` использует `controller.captureModelContext()` с fallback на файловую систему

### Технические детали

- Удалена функция `findNewestTaskDir` — больше не нужна
- Все эндпоинты используют `controller.task.messageStateHandler.getagentarioMessages()` для получения сообщений
- `/api/collect` теперь экспортирует markdown, raw JSON сообщений, контекст, логи и compaction файлы
