# Agentario v0.5.0

## Что нового

### Added

- **Структурная полоска контекста** в плашке задания: сегменты System / Rules / Tools / Chat (compressible); tooltip с разбивкой по категориям и списком rules по файлам.
- **Оценка бюджета контекста** в SDK — перед каждым API-запросом; в UI показывается разбивка pinned vs chat (≈ heuristic).
- **Agentic compaction (LLM summary)** для истории чата по умолчанию; при сбое summarizer — fallback на Basic.
- **Настройки сжатия:** Settings → Features — стратегия (Basic / Agentic), отдельная модель для summary.

### Changed

- Авто-сжатие использует **agentic** вместо basic; manual compact учитывает strategy и summarizer из настроек.
- `preserveRecentTokens` адаптируется к малым context window (LM Studio 8k–32k).

## Установка

1. Скачайте **`agentario-0.5.0.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
