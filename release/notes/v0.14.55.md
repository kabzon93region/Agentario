# Agentario v0.14.55

## Что нового

### Нативный REST API для автоматизации

Расширение Agentario теперь поднимает HTTP REST API внутри VS Code, что позволяет CLI и harness-серверу управлять агентом напрямую без посредника CDP (Chrome DevTools Protocol).

**Endpoints:**
| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/health` | Проверка доступности API |
| POST | `/api/new_task` | Создание нового задания |
| POST | `/api/followup` | Отправка продолжения |
| POST | `/api/cancel` | Отмена текущего задания |
| GET | `/api/status` | Статус: taskId, idle, messageCount |
| GET | `/api/messages` | Сообщения чата |
| GET | `/api/context` | Контекст модели |
| GET | `/api/export_chat` | Экспорт чата в markdown |
| GET | `/api/wait_idle` | Ожидание завершения агента |

**Активация:** установите `AGENTARIO_API_PORT=19231` в переменных окружения VS Code.

### Улучшения CLI

- `agentario-lab.cmd` теперь обращается напрямую к REST API расширения
- Автоматический fallback на harness если REST API недоступен
- Удалена команда `connect` (не требуется)

### Архитектурные изменения

**Было:**
```
CLI → Harness(19229) → CDP → globalThis.agentario → Controller
```

**Стало:**
```
CLI → Agentario API(19231) → Controller
Harness(19229) → Agentario API(19231) → Controller
```

Убрана зависимость от CDP bridge для лабораторной автоматизации. CDP по-прежнему доступен для отладки расширения (ext.* методы).
