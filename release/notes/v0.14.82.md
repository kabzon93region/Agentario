# v0.14.82 — Исправление кодировки и CLINE_DIR

## Fixed

- **Критическое исправление кодировки**: `readBody` теперь определяет charset из заголовка `Content-Type` запроса. PowerShell 5.1 отправляет тело в кодировке системы (cp1251), а Node.js читал как UTF-8 — кириллица в заданиях превращалась в `???` и модель получала невалидный промпт, из-за чего "угадывала" содержание задания
- `sendJson` теперь всегда указывает `charset=utf-8` в Content-Type ответа
- **CLINE_DIR изолирует профили**: `createStorageContext` теперь корректно получает `clineDir` из env-переменной / настроек / lab-режима — лабораторные сессии больше не попадают в основной `~/.agentario`
