## Agentario v0.14.58

### Новые возможности

- **Панель настроек Lab API Server** — новая вкладка "Lab API" в настройках Agentario:
  - Включение/выключение API сервера одним переключателем
  - Настройка порта (по умолчанию 19231)
  - Настройка пути к изолированному профилю (CLINE_DIR)
  - Автозапуск API сервера при старте Agentario
  - Кнопка проверки соединения с API

### Как использовать

1. Откройте настройки Agentario
2. Перейдите на вкладку "Lab API"
3. Включите "Lab API Server"
4. Настройте порт и путь к профилю (если нужно)
5. Перезапустите VS Code — API сервер запустится автоматически
