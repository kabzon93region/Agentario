# Agentario 0.8.5

## Изменения

- В системный промпт встроены правила поведения агента и работы с терминалом (PowerShell на Windows): приоритет IDE-тулсов, запрет записи файлов через shell, политика повторов.
- Улучшена валидация `run_commands`: распаковка stringified JSON, проверка типичных ошибок синтаксиса PowerShell.
- Усилено описание тулса `editor`.
- Ребрендинг SDK-промптов: `agentario.ts` вместо `cline.ts` (алиасы сохранены).

## Сборка

`build.cmd` → `release/agentario-0.8.5.vsix`
