# Agentario v0.4.20

## Что нового

### Fixed

- **Полоска контекста в плашке задания:** для LM Studio и Ollama показывается реальный размер окна модели, а не фиксированные 128K.
- **Rules:** системный промпт больше не попадает в список Rules как переключаемый файл — не «включается обратно» после отключения.

### Changed

- Обновлены глобальные правила (`agentario-global-rules.md`).
- Справка LM Studio (`lmstudio-system-prompt.md`) — только в `Documents/Agentario/docs/`, не в Rules.

## Установка

1. Скачайте **`agentario-0.4.20.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
