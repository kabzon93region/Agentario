# v0.14.79

## Fixed

- **Compaction progress visibility**: все промежуточные статусы суммаризации теперь отображаются в UI чата с эмодзи-префиксами (🔄 прогресс, ✅ результат, ❌ ошибка, 📊 статистика)
- **ChatRow info rendering**: добавлена специальная обработка для промежуточных сообщений компакции в UI — они отображаются как компактные строки с синей пульсирующей точкой и мелким шрифтом
- **filterCompactionInfoMessages**: обновлён фильтр — теперь сохраняет ВСЕ компакция-сообщения при сохранении истории, а не только финальный результат

### Details

Проблема: при запуске суммаризации (авто или ручной) в чате отображалось только одно сообщение (часто кракозябры), без информации о прогрессе, чанках, расчётах токенов и т.д. Пользователь не мог понять, закончилась суммаризация или нет, и на каком этапе она находится.

Корень проблемы:
1. Сообщения от `statusCallback` в agentic-compaction.ts не имели эмодзи-префиксов, поэтому UI не мог их распознать и рендерить
2. Функция `filterCompactionInfoMessages` фильтровала ВСЕ info-сообщения кроме "📊" и "✅", удаляя промежуточные статусы из истории
3. ChatRow.tsx имел обработку только для трёх паттернов ("compacting", "✅ Компакция завершена", "📊 Контекст:")

Исправление:
1. Добавлены эмодзи-префиксы ко ВСЕМ сообщениям statusCallback: 🔄 для прогресса, ❌ для ошибок, ✅ для результатов
2. ChatRow.tsx обновлён: добавлены обработчики для 🔄 (компактные строки с пульсирующей точкой) и ❌ (красный стиль ошибок)
3. filterCompactionInfoMessages теперь сохраняет 🔄 и ❌ сообщения при записи истории
4. formatCompactionStatus теперь добавляет ✅ префикс к финальному сообщению о результате
