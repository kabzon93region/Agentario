# v0.14.81 — Исправление доставки прогресса суммаризации

## Что исправлено

### Прогресс суммаризации теперь гарантированно виден

В версии 0.14.80 был баг: debounce timer в `emitInfo` сбрасывался при каждом вызове, из-за чего `postStateToWebview` никогда не срабатывал до завершения компакции. Пользователь видел только начальное сообщение «Полная суммаризация чата...» без какого-либо прогресса.

**Теперь:**
- Первое сообщение пушится немедленно (без debounce)
- Последующие сообщения используют debounce (150ms) для предотвращения спама
- Промежуточные статусы суммаризации гарантированно отображаются в UI чата

## Ожидаемое поведение

При полной суммаризации чата в UI последовательно появляются:

```
🔄 Полная суммаризация чата...
🔄 Суммаризация: N сообщений (user: X, assistant: Y), режим: полный чат
🔄 Map-reduce: M чанк(ов), ~Z ток. на входе, модель: model-id
🔄 Чанк 1/M: ~K ток. на входе
🔄 Чанк 1/M готов: ~L ток. на выходе
...
✅ Сжатие выполнено
📊 Контекст: ...
```

Без `in: 0 · out: 0 · total: 0` под info-строками.
