# Agentario v0.14.72

## Исправлено

### Суммаризация: формат для продолжения работы в чате

**Проблема:** Full-компакция (`compactionMode=full`) использовала wrap-up формат, который схлопывал ВСЕ промежуточные сообщения в один блок. Модель получала невосстановимый контекст без хронологии `[User]: ... [Agent]: ...`.

**Решение:** Full-компакция теперь использует стандартный подход (хронология с укороченными сообщениями). Wrap-up формат — только для `mode=manual` (завершённые задачи, где нужно сохранить только задание и ответ).
