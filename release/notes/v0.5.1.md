# Agentario 0.5.1

## MiMo Token Plan (Xiaomi)

- Исправлено применение Base URL из настроек провайдера в чате (Token Plan: `https://token-plan-cn.xiaomimimo.com/v1`).
- Контекстное окно и Supports Images из Model Configuration учитываются в сессии (полоска контекста, compaction).
- Кнопки **MiMo Token Plan** / **Pay-as-you-go** в настройках Xiaomi и OpenAI Compatible.
- Исправлен «залипающий» переключатель Supports Images.

## Как проверить

1. Settings → API → провайдер **Xiaomi** (или OpenAI Compatible).
2. Нажать **MiMo Token Plan (подписка)**.
3. Вставить API-ключ `tp-…`, при необходимости отключить Supports Images в Model Configuration.
4. Нажать **Готово**, начать новый чат — в полоске контекста должно быть ~1M, запросы на `token-plan-cn.xiaomimimo.com`.
