# Agentario v0.14.56

## Что нового

### Новые REST API endpoints для тестового пайплайна

Добавлено 5 новых endpoints для полного цикла тестирования без Harness:

#### GET /api/logs — чтение логов расширения

```
GET /api/logs?date=2026-07-31&lines=100
```

- date — дата лога (по умолчанию сегодня)
- lines — последние N строк (по умолчанию 200)
- Ответ: { path, lineCount, lines: string[], exists }

Логи хранятся в {clineDir}/data/logs/extension/agentario-{YYYY-MM-DD}.log

#### GET /api/compaction_files — compaction-файлы

```
GET /api/compaction_files?phase=map&chunk=1&read=true
```

- phase — фильтр по фазе (map | single)
- chunk — фильтр по номеру чанка
- read=true — вернуть содержимое файлов
- Ответ: { dir, files: [{ name, size, mtime, content? }] }

#### GET /api/collect — сбор сессионных файлов

```
GET /api/collect?outDir=Exports/my-test
```

Собирает в указанную директорию:
- ui_messages.json — сообщения чата
- api_conversation_history.json — история API
- extension.log — лог за сегодня
- compaction/ — compaction-файлы за сегодня

#### POST /api/install_vsix — установка VSIX

```
POST /api/install_vsix
Body: { "vsixPath": "Z:/T/Agentario/release/agentario-0.14.56.vsix" }
```

Выполняет code --install-extension=path. Ответ: { ok, stdout, error? }

#### POST /api/restart — перезапуск расширения

```
POST /api/restart
```

Выполняет workbench.action.reloadWindow. Ответ: { ok: true }

### Архитектура пайплайна

```
CLI/Агент → Agentario API(19231) → Controller
                                  → файловая система (логи, compaction)
                                  → VS Code CLI (install VSIX)
                                  → vscode.commands (restart)
```
