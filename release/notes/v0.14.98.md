# Agentario v0.14.98

## Что нового

### Fixed

- **Оптимизация чанков суммаризации** — переработана логика `packSummarizationUnits`:
  - Порог `soloThreshold` теперь равен `chunkSizeTokens` вместо фиксированных 2000 символов. Блок <= chunkSizeTokens упаковывается с другими, блок > chunkSizeTokens — solo
  - Solo-чанки получают лимит 2x `chunkSizeTokens` вместо 90% контекста модели
  - Добавлена защита от micro-flush: если текущий чанк заполнен менее 10% лимита, он не сбрасывается при встрече solo-блока. Устраняет создание чанков по 60-100 токенов
  - Удалена неиспользуемая константа `SOLO_CHUNK_CONTEXT_RATIO`

## Установка

1. Скачайте **agentario-0.14.98.vsix** из Assets релиза на GitHub.
2. VS Code - Extensions - ... - Install from VSIX.
