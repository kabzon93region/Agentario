# Agentario v0.14.39

## Что нового

### Changed

- Суммаризация: без `/no_think` и `thinking: false` — бюджет размышлений LM Studio не перебивается.
- Крупные `tool_result` / thinking — в отдельные чанки (до 90% окна модели), без обрезки 2k; метка продолжения между частями.
- Сырой `file` content в чанки суммаризации чата не кладётся (только путь).

Также включает UI-правки 0.14.38 (раскрывашка размышлений).

## Установка

1. Скачайте **`agentario-0.14.39.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.
