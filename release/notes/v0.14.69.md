## v0.14.69

### Исправления
- Lab API `/api/compact` возвращает `compacted: boolean`, `reason`, `contextChars` (до/после), `contextReduction` (%) — больше никаких ложноположительных результатов суммаризации
- Pipeline: валидация суммаризации проверяет реальный результат (`compacted`), различает skip (короткий чат) и failure (ошибка модели)
- Compaction coordinator: `compactTask()` возвращает `CompactTaskResult` с `compacted`, `reason`, `messagesBefore/After`
