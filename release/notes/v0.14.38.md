# Agentario v0.14.38

## Что нового

### Changed

- Размышления в ленте: во время стриминга раскрывашка открыта с полным текстом (без превью «последние 5 слов»); по окончании сворачивается.
- Раскрытый блок reasoning без ограничения высоты — виден весь текст; кнопка «Размышление» sticky к верху ленты при длинном содержимом.
- Статистика `in/out` под размышлением не дублируется, если следом есть текстовый ответ — строка stats остаётся под ответом.

## Установка

1. Скачайте **`agentario-0.14.38.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
