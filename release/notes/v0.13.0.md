# Agentario v0.13.0

## Что нового

### Семантический поиск для агента

Агент теперь умеет искать код **по смыслу**, а не только по regex. Новый тулс `semantic_search` использует существующий индекс embeddings — тот же, что отображается на вкладке «Индексация» в настройках.

- Ищет концептуально: «как работает компактация контекста», «где логика авторизации»
- Возвращает: путь к файлу, релевантность (0–1), текст найденного чанка
- Автоматически подключается если индекс существует для workspace
- Обновлён системный промпт — агент знает, когда использовать `semantic_search` vs `search_codebase`

### Улучшения суммаризации

- **Автосуммаризация** теперь корректно срабатывает при превышении порога контекста (подсчёт токенов включает system prompt + tools).
- **Thinking-теги** (`<think>`, `<thinking>`, `[thinking]`) вырезаются из ответа суммаризатора — модели больше не «думают» в чат.
- **Отладочные файлы** суммаризации логируются в `~/Documents/agentario-compaction-debug/`.

## Установка

1. Скачайте **`agentario-0.13.0.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
