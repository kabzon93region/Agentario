# Agentario v0.4.9

## Что нового

### Fixed

- **Индексация больших проектов** (мобильные/Flutter/Android с тысячами файлов): `Invalid string length` при сохранении индекса — теперь **шардированное хранение** без лимита размера (`indexes/{hash}/meta.json` + отдельный JSON на каждый файл).
- **«Очистить индекс»** не удалял файлы и не прерывал сборку — исправлено: поиск по `workspacePath`, принудительная остановка, удаление всех legacy и sharded файлов.
- Прогресс и размер индекса теперь отображаются в реальном времени.

### Changed

- Чанки под embedding-модели с **контекстом 2048 токенов** и eval batch size 2048: размер чанка ~1024 tok, **нахлёст 17.5 %**, batch запросов ≤ 2048 tok суммарно. Лимит чанков на файл снят (только 2 MB на чтение файла).
- Правило **bump версии после каждого изменения** усилено в `.cursor/rules/DEVELOPMENT_RULES.mdc` (приоритет, агрессивная формулировка).

### Added

- Документация индексации LM Studio (domain type → Embedding, headless, контекст).
- Скрипт `lmstudio-headless-server.cmd`.
- `publish-release.cmd` + шаблоны GitHub Release.

## Установка

1. Скачайте **`agentario-0.4.9.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей
