# Agentario 0.5.3

## Сброс и логи

- **Settings → Общие → Сбросить Agentario** — полный сброс настроек, API-ключей, пресетов, индексации, истории чатов и кеша. Пользовательские файлы правил в `Documents/Agentario/Rules` сохраняются; `agentario-global-rules.md` восстанавливается из VSIX.
- **Открыть папку логов** — `%USERPROFILE%\.agentario\data\tasks` (в каждой подпапке задачи: `ui_messages.json`, `api_conversation_history.json`).

## MCP

- При первой установке расширения рекомендуемый набор MCP создаётся автоматически.
- По умолчанию **включены**: `sequential-thinking`, `Context7`.
- **Доступны, но выключены**: memory, memory-slim, sequential-thinking-slim, Charlotte, playwright, trueline, github.
- В списке MCP — подписи вида `Memory (standard)` / `memory-slim (alternate light)`.
