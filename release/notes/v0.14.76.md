# v0.14.76

## Fixed

- **Summarization format**: wrap-up mode (секция "Находки из файлов") теперь активируется ТОЛЬКО для legacy manual compact без заданного `compactionMode`. Context/full compaction через `/api/compact` используют стандартный диалоговый формат суммаризации (`[User]: ... [Agent]: ...`) вместо wrap-up блока

### Root cause

`compactSessionMessages()` хардкодил `mode: "manual"` для всех вызовов `/api/compact`. В `agentic-compaction.ts` условие `if (isManual)` активировало wrap-up mode для ВСЕХ manual compaction, включая context/full. Wrap-up промпт (`WRAP_UP_PROMPT_AFTER`) требовал формат "Находки из файлов" / "## Files" вместо стандартного диалогового формата.

### Fix

Добавлено условие `useWrapUp = isManual && compactionMode !== "context" && compactionMode !== "full"` — wrap-up активируется только для legacy manual compact без конкретного `compactionMode`.
