# Agentario v0.14.40

## Что нового

### Added

- **Саммари больших файлов:** при `read_files` без `start_line`/`end_line` для файлов >50 KB — блок `=== FILE SUMMARY ===` (LLM или outline), затем превью первых 200 строк.
- **UI:** саммари в аккордеоне «Саммари файла» в ленте чата; диапазон строк из заголовка PREVIEW.
- **Контекст:** MessageBuilder при усечении сохраняет FILE SUMMARY, обрезает превью.

### Changed

- `toolContextMetadata.summarizeLargeFile` из session-factory доходит до file-read executor.
- Индексация: статус isIndexing сразу при старте build; UI показывает progress bar N/M с обновлением по файлам.

Также включает изменения 0.14.39 (суммаризация чата) и 0.14.38 (UI reasoning).

## Установка

1. Скачайте **`agentario-0.14.40.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.
