# Agentario v0.14.97

## Что нового

### Fixed

- **Дублирование сообщений компакции в UI** — диагностические сообщения суммаризации ("Расчёт:", "Units:", "Чанк N/M:") теперь логируются только в extension host, а не отображаются в чате. Пользователь видит только ключевые статусы: контекст до, индикатор работы, результат и контекст после компакции

### Improved

- **Улучшен промпт суммаризации** — добавлены правила для корректного определения основного проекта vs. зависимостей:
  - Правило 6.1: определяй основной проект/задачу диалога, не путай зависимости с основным проектом
  - Правило 6.2: сохраняй задание/цель каждого сообщения пользователя
  - DEFAULT_PROMPT_AFTER: акцент на "зависимости второстепенны, основной проект первичен"
  - WRAP_UP правило 1.5: аналогичное указание для wrap-up суммаризации

## Установка

1. Скачайте **agentario-0.14.97.vsix** из Assets релиза на GitHub.
2. VS Code - Extensions - ... - Install from VSIX.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей
