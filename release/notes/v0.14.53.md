# v0.14.53 — Agentario Lab: Full Pipeline

Дата: 2026-07-30

## Что нового

### Полный пайплайн автоматизации

lab.run выполняет полный цикл одним вызовом:
1. Запуск VS Code
2. Создание задачи
3. Ожидание ответа модели
4. Экспорт чата (полный: thinking, tools, commands, agent text)
5. Экспорт контекста модели
6. Сбор логов расширения + файлов компакции
7. Скриншот

### Новые lab-методы

- lab.run — полный цикл автоматизации
- lab.export_context — экспорт контекста модели
- lab.collect_session_files — сбор всех файлов сессии

### Улучшенный экспорт чата

lab.export_chat теперь включает thinking-блоки, tool calls/results, system info, форматированные команды.
