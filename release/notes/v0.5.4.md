# Agentario 0.5.4

## Логи и отладка

- **Открыть папку логов** теперь открывает `~/.agentario/data/logs` (extension/, ui/, README с путём к tasks/).
- Логи расширения и UI-событий (экраны настроек, клики по пресетам и вкладкам) пишутся в файлы по датам.

## Пресеты модели

- Исправлено переключение пресетов с первого клика: форма API и настройки провайдера обновляются сразу.

## Индексация

- Три режима: локальный без AI, локальный AI (LM Studio/Ollama), удалённый AI с указанием URL и модели embeddings.

## MCP

- При обновлении с 0.5.3 автоматически добавляются серверы из шаблона v2: `memory-slim`, `sequential-thinking-slim`, `charlotte` (если их ещё нет в настройках).
