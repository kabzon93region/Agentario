# Agentario v0.14.95

## Что нового

### Fixed
- **CycleDetector не обнаруживал зацикливание thinking** — `onThinking` вызывался в `content_end` handler, но `event.reasoning` мог быть пустым (контент уже приходил через `content_start` deltas). Исправлено: используется накопленный текст из `getStreamingReasoningText()` перед очисткой буфера

## Установка

1. Скачайте **`agentario-0.14.95.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей
