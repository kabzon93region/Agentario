# v0.15.0 — Summarization Abort & Restart

## Что нового

### Кнопка перезапуска зависших чанков
- При суммаризации каждый чанк теперь показывает кнопку "⟳ Повторить"
- Кнопка abort текущий запрос к модели и автоматически переотправляет тот же чанк (до 3 ретраев)
- После успешной обработки чанка кнопка disappears

### Safety abort для reasoning-only
- Если модель генерирует 1000+ reasoning-чанков подряд без текста — запрос автоматически прерывается
- Защита от бесконечных reasoning-циклов (как было в v0.14.98 с qwen3.5-4b-mtp)

### AbortSignal через pipeline
- Прокинут AbortSignal через collectStreamingChunks -> generateSummary -> runAgenticCompaction
- Позволяет прервать зависший запрос на любом уровне

## Исправления
- statusCallback прогресс чанков снова отображается в UI (а не только в логах)
- Добавлено поле metadata в AgentarioMessage для action-кнопок
