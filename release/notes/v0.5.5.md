# Agentario 0.5.5

## MCP — исправление отсутствующих серверов

**Причина:** шаблон MCP (memory-slim, sequential-thinking-slim, charlotte) записывался в VS Code globalStorage, а расширение читало другой файл — `~/.agentario/data/settings/agentario_mcp_settings.json`.

**Исправление:** seed/merge в канонический путь, миграция из legacy globalStorage, перезагрузка McpHub при обновлении шаблона v3.

После установки: **Reload Window** — в MCP должны появиться memory-slim, sequential-thinking-slim, charlotte (часть disabled — норма).

## Пресеты модели

- Настройки провайдера (Base URL и т.д.) применяются до обновления формы API.
- При переключении пресета форма не показывает дефолтные PAYG/localhost, пока не загрузится конфиг.
- Plan/Act вкладка сбрасывается при смене пресета.

Установка: `release/agentario-0.5.5.vsix`
