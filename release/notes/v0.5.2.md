# Agentario 0.5.2

## Пресеты модели

- Сохранение текущих настроек Plan/Act (провайдер, модели, Base URL, Model Configuration) в именованный пресет.
- Быстрое переключение из чата: кнопка справа от названия модели, перед Plan/Act.
- API-ключи **не** сохраняются в пресет — остаются в локальном хранилище.

## Как проверить

1. Settings → API → настройте LM Studio или MiMo.
2. Внизу секции «Пресеты модели» введите имя и нажмите «Сохранить текущие настройки».
3. Переключите другой провайдер, затем в чате выберите пресет из выпадающего списка.
