# v0.14.74

## Проблема

В v0.14.73 token estimator ограничивал tool_result лимитом 2000 символов, а buildSummarizationUnits использовал flattenToolResultContentFull без лимита. Это приводило к расхождению:

- Estimator: 7,372 токена (заниженный)
- Реальные чанки: 9,097 токенов (точный)

## Что исправлено

- createTokenEstimator теперь использует estimateToolResultProviderLength (без лимита) вместо estimateToolResultSerializedLength (лимит 2000)
- Сообщение Расчёт теперь показывает: общее количество токенов диалога, сколько отдано на суммаризацию, сколько сохранено
