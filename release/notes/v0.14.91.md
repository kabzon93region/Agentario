# Agentario v0.14.91

## Что нового

### Fixed

- **Критический фикс: потеря содержимого tool results при компакции контекста** — функции `flattenToolResultContent` и `flattenToolResultContentFull` не обрабатывали structured tool outputs (`ToolOperationResult[]` с полями `query`, `result`, `error`, `success`), возвращаемые инструментами `run_commands` и `read_files`. Эти объекты попадали в `default: return ""` и терялись при компакции, что приводило к ложному выводу суммаризатора "файлы недоступны". Добавлена функция `formatStructuredToolEntry` для извлечения содержимого из structured entries
- **Усилен промпт суммаризации** — добавлено правило: ошибки tool call (например, ENOENT) не означают отсутствие файла; файл может быть прочитан другим tool call

## Установка

1. Скачайте **`agentario-0.14.91.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
