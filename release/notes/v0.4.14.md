## Agentario 0.4.14

### Исправлено

- **BodyTimeoutError при длинных ответах LM Studio:** стриминг больше не обрывается через ~5 минут из‑за внутреннего лимита Node/undici. Используется значение «Таймаут запроса» из настроек LM Studio (по умолчанию 10 минут).

### Установка

Скачайте `agentario-0.4.14.vsix` из Assets и установите через VS Code: Extensions → «…» → Install from VSIX.
