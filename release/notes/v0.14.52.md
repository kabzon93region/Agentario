# v0.14.52 — Agentario Lab

**Дата:** 2026-07-30

## Что нового

### Agentario Lab — автоматизация тестов

Добавлена система программного управления тестовым VS Code для end-to-end тестирования Agentario без ручных кликов.

**Возможности:**
- High-level API: создание задач, ожидание ответа модели, экспорт чата, скриншоты
- CLI-обёртка `scripts/agentario-lab.cmd` для Windows
- TypeScript HTTP-клиент `lab-client.ts`
- Запуск с release VSIX (`--vsix PATH`)
- Изолированный профиль `~/.agentario-lab`
- Кросс-платформенные пути (Windows/macOS/Linux)

### Использование

```bat
:: Запуск тестового VS Code
scripts\agentario-lab.cmd start --workspace Z:\T\TEMO --vsix release\agentario-0.14.52.vsix

:: Создание задачи и ожидание ответа
scripts\agentario-lab.cmd new-task "Проанализируй структуру проекта"
scripts\agentario-lab.cmd wait-idle --timeout 600000

:: Экспорт результата
scripts\agentario-lab.cmd export Exports\lab-run.md

:: Остановка
scripts\agentario-lab.cmd stop
```

### curl API

```bash
curl localhost:19229/api -d '{"method":"lab.status"}'
curl localhost:19229/api -d '{"method":"lab.new_task","params":{"text":"Hello"}}'
curl localhost:19229/api -d '{"method":"lab.wait_idle","params":{"timeout":600000}}'
curl localhost:19229/api -d '{"method":"lab.export_chat","params":{"outPath":"Exports/lab.md"}}'
```
