# Agentario v0.14.45

## Что нового

### Fixed

- Рассинхрон полоски контекста и автокомпакции после смены окна LM Studio mid-session: live `loaded_context_length` форсится при компакции/сессии и синхронизируется с UI.
- Полоска прогресса: при более высокой свежей оценке контекста показывается она (а не устаревший `tokensIn`); `context_stats` перед компакцией обновляет `contextBudget` в чате.

## Установка

1. Скачайте **`agentario-0.14.45.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
