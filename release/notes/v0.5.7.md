# Agentario 0.5.7

## Исправлено

- Переключение пресетов: Base URL и reasoning из provider config пресета теперь напрямую закрепляются в `providers.json` после синхронизации модели. Это убирает возврат к дефолтному Xiaomi при первом клике на LM Studio.
- Переключение Plan/Act: `ApiOptions` больше не пересоздаётся целиком при смене вкладки, поэтому загруженный список моделей Xiaomi по API-ключу не сбрасывается в ручное поле.
- В лог расширения добавлена строка `[ModelProfilePreset] Provider config persisted...`, чтобы видеть применённый Base URL/API line.

Установка: `release/agentario-0.5.7.vsix`
