# Agentario v0.14.36

Релиз после **v0.14.32**. Фокус: стабильность локальных моделей (LM Studio), полоска контекста, обзор проекта без лишних лупов.

## Что нового

### Fixed

#### Контекст и полоска на плашке таска
- Полоска больше не прыгает вверх по `tokensIn` и вниз на заниженный `totalEstimated` при старте следующего хода — предпочитается последнее измеренное usage провайдера.
- `totalEstimated` считает chat как у API (без лишней обрезки tool_result до 2k как у compaction) + EMA-калибровка по `tokensIn`.
- В расшифровке разделены **«В текущем запросе»** (заполнение окна) и **«Сумма за весь таск»** (накопленные prompt/completion). Знак `≈` только для оценки.

#### LM Studio / Ollama
- Явный `maxTokensPerTurn = 4096` (иначе сервер часто режет всю генерацию на 512 токенов — обрыв отчётов mid-sentence).
- **Важно:** бюджет размышлений (thinking) и лимит длины ответа (max tokens) в LM Studio — разные настройки. Если оба = 512, thinking может съесть почти весь бюджет, и ответ обрежется. Для длинных отчётов поднимите **max tokens** (Agentario с 0.14.36 шлёт 4096) и при необходимости thinking budget.

#### Агент / tools / промпт
- `attempt_completion`: маппинг `summary`/`text` → `result`; отказ на пустом `{}` с понятной ошибкой.
- Промпт обзора: старт с `git status` + корневые `read_files`, не с 2–3 пустых `semantic_search`.
- Блок повторного чтения одного пути (>2 `read_files`); unwrap quoted shell cmds; жёстче reject `ls`/`dir`/`Get-Content`.
- Повтор одинаковых `run_commands`; `&&` в PowerShell; demote vendor paths в `semantic_search`.

### Changed (0.14.29–0.14.31, если ещё не ставили)
- Ребрендинг Cline → Agentario (UI, логотипы, activity bar).

## Установка

1. Скачайте **`agentario-0.14.36.vsix`** из Assets.
2. VS Code → Extensions → `...` → **Install from VSIX**.
3. Провайдер **LM Studio** или **Ollama** — см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель).

## Требования

- VS Code 1.84+
- LM Studio или Ollama для локальных моделей
- Рекомендуется: в LM Studio **не** держать жёсткий лимит ответа на 512, если нужны длинные `attempt_completion` / отчёты
