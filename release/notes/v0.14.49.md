# Agentario v0.14.49 — Критичные исправления (Волна 1)

## Исправлено
- **`read_files` читал из папки VS Code:** относительные пути резолвились через `process.cwd()` (= папка установки IDE), а не рабочую папку проекта. Исправлено: используется session cwd.
- **Суммаризация раздувала контекст (78k из 5.5k):** модель отвечала только reasoning-каналом, и весь reasoning (без лимита) принимался как summary. Теперь reasoning ограничен, output > 90% input → reject.
- **`search_codebase` не блокировал повторы:** в отличие от `semantic_search`, повторный идентичный query не отклонялся мгновенно, что позволяло агенту зацикливаться.

## Изменено
- `read_files` description: большие файлы без start/end → FILE SUMMARY + превью (экономия контекста).
- Системный промпт: описание FILE SUMMARY, fallback при недоступности `semantic_search`.
- `DEFAULT_SUMMARY_MAX_OUTPUT_TOKENS` = 4096 (был 0 = без лимита).
