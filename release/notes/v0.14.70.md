## v0.14.70

### Forced wrap-up compaction

Принудительная суммаризация теперь работает корректно для завершённых диалогов:

- **Wrap-up режим** (mode: manual): сохраняет задание пользователя и финальный ответ агента, сжимает промежуточную работу (tools, thinking, прочитанные файлы) в качественный summary
- **Находки из файлов**: суммаризатор получает запрос на краткий итог + список ключевых фактов по каждому прочитанному файлу
- **Проброс причин**: skipReason пробрасывается из SDK через coordinator -> API

### Реализация

- findWrapUpRange() вычисляет диапазон fold/preserve: [firstTask, summary, lastAnswer]
- findLastSubstantiveAssistantIndex() ищет последний assistant с текстовым ответом
- Wrap-up промпт: WRAP_UP_PROMPT_BEFORE / WRAP_UP_PROMPT_AFTER с секцией Находки из файлов
- CoreCompactionResult.skipReason специфичные причины пропуска: no_foldable_middle, empty_summary, summary_error
