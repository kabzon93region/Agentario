# v0.14.77

## Fixed

- **Token alignment**: `providerScale` теперь применяется ко ВСЕМ расчётам токенов в compaction (status message, coordinator, agentic-compaction) — цифры согласованы с UI
- **Summarization quality**: улучшен промпт суммаризации — добавлены правила сохранения фактов, выводов и последовательности действий агента
- **Compression aggressiveness**: снижена агрессивность сжатия с "в 2 раза" до "в 1.5-2 раза" для лучшего сохранения контекста

### Details

#### Token alignment
- Compaction status message теперь показывает `≈{scale}x` коэффициент для прозрачности
- Coordinator передаёт `providerScale` через `compactSessionMessages` → `createContextCompactionPrepareTurn` → `runAgenticCompaction`
- Все `tokensBefore` и `chatTokens` расчёты масштабированы по `providerScale`

#### Summarization quality
- Добавлены правила 6-7 в промпт суммаризации:
  - Сохранять все найденные факты, выводы, результаты анализа
  - Сохранять последовательность действий агента
- Снижена агрессивность сжатия: "в 1.5-2 раза" вместо "в 2 раза"
- `DEFAULT_PROMPT_AFTER` теперь напоминает о сохранении ключевых фактов
