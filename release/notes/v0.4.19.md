# Agentario v0.4.19

## Что нового

### Added

- **trueline-mcp** в рекомендуемом MCP-шаблоне — надёжные правки файлов с проверкой hash (`trueline_read` → `trueline_edit`).
- **LM Studio (чат):** в выпадающем списке моделей — тип и `loaded`; загруженные модели сверху.

### Changed

- Обновлены системный промпт и global rules: не писать файлы через PowerShell; когда использовать `editor` vs trueline.

## Установка MCP

```bat
setup-mcp.cmd
```

Перезапустите VS Code → Agentario → MCP Servers → проверьте **trueline**.

## Установка VSIX

Скачайте `agentario-0.4.19.vsix` из Assets.
