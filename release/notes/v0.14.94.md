# Agentario v0.14.94

## Что нового

### Fixed
- **Корректные категории context budget после компакции** — убран хардкод-контекст-бюджет (rules=3000, tools=3000) из координатора компакции. SDK сам рассчитывает и эмитит правильный contextBudget с реальными категориями (system, rules, tools, mcp, skills, chat) при следующем API-запросе. Исправляет отображение прогресс-бара после компакции, когда все категории показывали 0 кроме chat

### Added
- **Защита от зацикливания агента** — `CycleDetector` теперь трекает 3+ одинаковых подряд tool calls (не только thinking). При обнаружении зацикливания в чат добавляется system message с просьбой перечитать задание, проанализировать последние действия и попробовать другой подход

## Установка

1. Скачайте **`agentario-0.14.94.vsix`** из Assets релиза на GitHub.
2. VS Code → Extensions → `...` → **Install from VSIX**.

## Требования

- VS Code 1.84+
- LM Studio или Ollama — для локальных моделей (см. [README](https://github.com/kabzon93region/Agentario#lm-studio-локальная-модель))
