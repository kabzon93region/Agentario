# Agentario v0.5.12

## 🚀 Основные изменения

### 🎯 Пресеты модели (Model Presets)
- **Пресеты модели:** сохранение полного набора настроек Plan/Act (провайдер, модель, Base URL, Model Configuration) и быстрое переключение из чата
- Экран управления пресетами в Settings → API Configuration
- Исправлены race conditions и stale updates при переключении пресетов

### 📊 Контекст и сжатие
- **Структурная полоска контекста** в плашке задания: сегменты System / Rules / Tools / Chat
- **Оценка бюджета контекста** (`estimateContextBudget`) — отображается в UI
- **Agentic compaction (LLM summary)** для чата по умолчанию
- **Настройки сжатия:** Settings → Features — стратегия (Basic / Agentic), отдельная модель для summary

### 🔧 Индексация и поиск
- **Шардированное хранение индекса** — поддержка больших проектов без ограничения размера
- **Прогресс индексации** в UI: текущий файл, процент, размер индекса на диске
- **Индексация больших файлов:** текстовые форматы читаются полностью без лимита 2 МБ
- Выбор embedding-модели LM Studio в экране «Индексация кода»

### 🌐 Провайдеры и модели
- **Xiaomi MiMo:** отдельный экран настроек, кнопки Token Plan / Pay-as-you-go
- **MiMo Token Plan:** Base URL, Model ID, контекст 1M
- **LM Studio (агент):** в списке моделей отображаются тип и статус `loaded`
- Исправлен `requestTimeoutMs` — теперь применяется корректно к HTTP-стримингу

### 🛠️ MCP и интеграции
- **MCP:** seed и merge шаблона теперь пишут в `~/.agentario/data/settings/agentario_mcp_settings.json`
- **Автоматическая установка** рекомендуемого набора MCP при первом запуске
- Альтернативные MCP: `memory-slim`, `sequential-thinking-slim`, **Charlotte**

### 📝 Правила и промпты
- **Сброс Agentario** (Settings → Общие): полная очистка настроек, кеша, индексации, истории чатов и MCP
- **Кнопка «Стоп»** в чате во время работы агента
- **Кнопка «Очистить»** (индексация) — исправлена, теперь работает корректно
- **Таймаут bash-команд** ограничен 5 минутами (не зависит от `requestTimeoutMs` API)

### 📋 Логирование и отладка
- Файловые логи расширения и UI: `~/.agentario/data/logs/extension/` и `logs/ui/`
- Кнопка **«Открыть папку логов»** — быстрый доступ к `~/.agentario/data/logs`

### 🌍 Локализация и UI
- Русская локализация: Customize (Rules/Hooks/Skills), MCP, Debug, onboarding LM Studio
- Экспорт чата в Markdown (диалог сохранения, `Documents/Agentario/Exports`)
- Заголовки сообщений: роль (User / Agentario / Thinking) и дата/время
- Подвал статистики сообщения: tokens in/out/total, время ответа, tok/s

## 🐛 Исправления

- **Xiaomi — список моделей:** `refreshOpenAiModels` теперь принимает `provider_id` и подставляет API-ключ нужного провайдера
- **Пресеты — race condition:** `applyModelProfilePreset` теперь сам вызывает `postStateToWebview` сразу после применения
- **Пресеты — stale partial update:** `updateApiConfigurationPartial` игнорирует запросы в течение 2 с после применения пресета
- **Кнопка «Очистить» (индексация):** при отмене диалога кнопка разблокируется
- **Удаление индекса:** учитывает `realpath` workspace, несколько вариантов хеша
- **LM Studio / BodyTimeoutError:** настройка «Таймаут запроса» теперь реально применяется к HTTP-стримингу
- **Таймаут bash-команд:** `resolveAgentToolTimeoutMs` ограничен максимум 5 минутами

## 📦 Установка

1. Скачайте `agentario-0.5.12.vsix` из assets релиза
2. VS Code → Extensions → `...` → **Install from VSIX...**
3. Выберите скачанный файл
4. Перезагрузите окно VS Code
