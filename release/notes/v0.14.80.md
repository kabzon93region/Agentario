# v0.14.80 — Исправление прогресса суммаризации в UI

## Что исправлено

### Прогресс суммаризации теперь виден в чате

- `emitInfo` теперь гарантированно пушит состояние в webview через debounced `postStateToWebview` (150ms) — промежуточные статусы суммаризации отображаются в UI чата в реальном времени
- Monotonic ts для info-сообщений: несколько статусов за одну миллисекунду больше не сливаются в одно сообщение
- Добавлена map-reduce сводка в начале этапа суммаризации: количество чанков, токены на входе, модель

### Русские строки компакции в ChatRow

- `isCompacting` теперь матчит русские строки «Полная суммаризация», «Сжатие контекста» (а не только английские "compacting")
- При компакции отображается реальный текст сообщения вместо захардкоженного «Сжатие контекста...»

### Скрытие нулевых токенов

- `formatMessageStatsLine` больше не показывает `in: 0 · out: 0 · total: 0` когда нет реальных токенов, стоимости или длительности

### Унификация эмодзи-префиксов

- Все `statusCallback` в `agentic-compaction.ts` унифицированы с эмодзи-префиксами: 🔄 прогресс, ✅ результат, ❌ ошибка

## Ожидаемое поведение

При полной суммаризации чата в UI последовательно появляются:

```
🔄 Полная суммаризация чата...
🔄 Суммаризация: N сообщений (user: X, assistant: Y), режим: полный чат
🔄 Map-reduce: M чанк(ов), ~Z ток. на входе, модель: model-id
🔄 Чанк 1/M: ~K ток. на входе
🔄 Чанк 1/M готов: ~L ток. на выходе
...
✅ Сжатие выполнено
📊 Контекст: ...
```

Без `in: 0 · out: 0 · total: 0` под info-строками.
