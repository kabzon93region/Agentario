## Agentario 0.4.17

### Добавлено

- **Кнопка «Стоп»** в поле ввода чата — прерывает текущую работу агента (как в Cursor). Работает при стриминге и ожидании подтверждения инструментов. Esc — по-прежнему альтернатива.

### Установка

Скачайте `agentario-0.4.17.vsix` из Assets и установите через VS Code: Extensions → «…» → Install from VSIX.
